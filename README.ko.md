# xiao-ui-theme-ts

DeepSeek Harness용 **고도로 사용자 지정 가능한 테마 플러그인** (기본적으로 "소(魈)" 옥색 녹색 스타일). DeepSeek Harness의 웹 인터페이스에 테마를 적용합니다. 색상, 마스코트 배지, 프로스트 배경, 음성 주입 등을 모두 설정할 수 있습니다. 기본은 소 스타일의 옥색/에메랄드 테마이지만, 강조 색상, 배지 텍스트, 음성, 배경 투명도 등을 자유롭게 조정해 나만의 테마를 만들 수 있습니다.

## 이것은 무엇인가

DeepSeek Harness의 웹 인터페이스에 고도로 사용자 지정 가능한 테마를 적용합니다. **기본은 소의 옥색 녹색 스타일** (옥색 팔레트 + 마스코트 배지 + 소풍 음성 + 프로스트 배경)이지만 모든 항목을 수정할 수 있습니다. 강조 색상, 배지 텍스트, 음성 켜기/끄기·언어·내용, 배경 이미지와 투명도. 또한 세션에 **소풍 말투**를 선택적으로 주입할 수 있습니다. 어시스턴트가 소처럼 말하게 하려면 켜고, 아니면 끄세요. 단, 바뀌는 것은 말투·문체뿐이며 답변 내용은 전혀 바뀌지 않습니다.

## 기능

- **사용자 지정 가능한 팔레트 (기본 옥색/에메랄드)** : 라이트/다크 옥색 팔레트. 강조 색상은 컬러 휠로 선택하고, 테마 자체는 설정에서 한 번에 끌 수 있습니다.
- **마스코트 배지** : 드래그 가능·접을 수 있는 배지 (오른쪽 아래). 제목과 부제는 임의 텍스트로 변경 가능.
- **소풍 음성** : 시스템 프롬프트에 소풍 말투 설명을 주입 (켜기/끄기 가능). 중국어/영어 템플릿 또는 직접 작성한 커스텀 프롬프트 지정 가능.
- **프로스트 배경** : 배경 이미지 설정 가능 (플러그인 상대 경로, 로컬 절대 경로, 또는 직접 업로드). 블러 강도와 UI 투명도도 조정.
- **UI·사이드바 투명도 제어** : UI 불투명도(0.3–0.9)는 메인 영역을, 사이드바 불투명도(0–1)는 좌우 사이드바를 각각 제어. 100% 완전 불투명하게 하면서도 배경은 항상 일부 비칩니다.
- **강조 색상** : 기본은 소의 옥색 녹색. 컬러 휠로 임의의 강조 색상을 선택 가능. 패널 면, 테두리, 브랜드 색상, 사이드바, 배경 그라데이션이 연동해 바뀌며, 변경 후 저장됩니다.
- **설정 페이지** : 마스터 스위치, 강조 색상, 음성 주입, 템플릿 언어, 커스텀 프롬프트, 아바타 경로, 마스코트 제목/부제, 프로스트 배경(켜기/경로/업로드/블러/투명도), UI 및 사이드바 불투명도.

## 요구 사항

- DeepSeek Harness (`dsh` 사용 가능)
- Node.js (≥ 18 권장)
- [pnpm](https://pnpm.io/)

## 온라인 설치 (빠르게)

1. `dsh` 명령이 사용 가능한지 확인합니다.
2. 패키지 이름으로 설치 (npm, 권장):
```bash
dsh plugin --profile web add xiao-ui-theme-ts
```
   또는 GitHub 릴리스의 tgz로 직접 설치:
```bash
dsh plugin --profile web add https://github.com/jinxlux/xiao-theme-dsh-ui-plugin/releases/download/xiao-ui-theme-ts-0.6.0/xiao-ui-theme-ts-0.6.0.tgz
```

## 소스에서 설치 (클론)

```bash
git clone <copied-repo-url>
cd xiao-ui-theme-ts

pnpm install       # 빌드 의존성 설치
pnpm run build     # lib/ 생성 (ESM Host + ModuleLoader Client + 타입 정의)
pnpm run check     # 선택: 산출물이 dsh 플러그인 계약을 만족하는지 검증
```

이후 번들로 DSH 프로필에 추가합니다:

```bash
# 상대 경로 (리포지토리와 같은 레벨에서 실행)
dsh plugin --profile web add "./xiao-ui-theme-ts"
# 또는 절대 경로
dsh plugin --profile web add "D:/.../xiao-ui-theme-ts"
```

> `dsh plugin add`는 패키지를 프로필에 설치하고, `dsh.bundle` 선언 덕분에 **번들 스택에 자동으로 연결**됩니다 — 수동 설정 불필요.
> 테마를 반영하려면 DSH Web을 새로고침/재시작하세요.

## 사용법 및 설정

- DSH Web → **설정 → 소 테마** : 마스터 스위치, 강조 색상, 음성 주입, 템플릿 언어, 커스텀 프롬프트, 아바타 경로, 마스코트 제목/부제, 프로스트 배경(켜기/경로/업로드/블러/투명도), UI 불투명도, 사이드바 불투명도.
- **강조 색상** : 컬러 휠로 강조 색상 선택 (기본 소의 옥색 녹색 `#2E8B72`). 패널 면, 테두리, 브랜드 색상, 사이드바, 배경 그라데이션이 연동해 바뀝니다. 의미 있는 상태 색상(오류/경고/성공)은 고정되며 강조 색상을 따르지 않습니다.
- **마스코트 텍스트** : 배지 제목(기본 "靖妖傩舞")과 부제(기본 "别挡路")는 임의 텍스트로 변경 가능. 제목을 비우면 기본으로 돌아갑니다.
- **UI 불투명도** : 메인 영역을 제어. 범위 0.3–0.9로, 배경이 항상 약 10% 이상 보이도록 상한이 설정되어 있습니다.
- **사이드바 불투명도** : 좌우 사이드바를 각각 제어. 범위 0–1, 100% 완전 불투명까지 가능. 왼쪽은 DSH 기본 사이드바, 오른쪽은 서드파티 better-sidebar 플러그인(`data-dsh-panel` / `data-dsh-pane`)에도 적용됩니다. 해당 플러그인이 설치되지 않았으면 자동으로 무시됩니다.
- 변경 사항은 **즉시 반영**되며 DSH 재시작이 필요 없습니다.
- 설정은 `~/.dsh/xiao-theme.json`에 저장됩니다. 업로드한 배경 이미지는 `~/.dsh/xiao-theme-uploads/`에 저장됩니다(사용자 단위, 리포지토리에 포함 안 됨).

## 주의 사항

- **로컬 설치에서 원격 설치로 전환** : 처음에 로컬 경로로 설치한 경우(`dsh plugin add ./xiao-ui-theme-ts`,
  DSH는 `link:` 의존성으로 기록) 나중에 패키지 이름 / tgz로 원격 설치로 전환할 때는 남아 있는 link를
  먼저 제거하세요. 그렇지 않으면 pnpm이 link를 따라 로컬 `node_modules`로 돌아가 심볼릭 링크 `EPERM`
  (`@types/node`)으로 실패합니다. 먼저 제거한 뒤 다시 시도하세요:
  ```bash
  dsh plugin --profile web remove xiao-ui-theme-ts
  dsh plugin --profile web add xiao-ui-theme-ts
  ```
- **마운트 전에 빌드** : `lib/`는 빌드 산출물로 커밋되지 않습니다. 클론 후 `pnpm install && pnpm run build`를 먼저 실행하세요. 빌드되지 않은 디렉터리를 `dsh plugin add`하면 `lib/`가 없어 로딩에 실패합니다.
- 기본 아바타/배경은 **패키지 내 상대 경로**(`resource/avatar.png`, `resource/bg.svg`)를 사용해 머신 간에 읽을 수 있습니다. 빌드 후 `resource/`를 `lib/`와 같은 레벨로 유지하세요(현재 구성 성립).
- 소풍 음성 프롬프트는 DSH의 `systemPrompt` 조립에 의존합니다. 사용 중인 agent 프리셋이 프롬프트를 persona만 남기도록 거르는 경우, 또는 **complete persona**를 쓰는 경우 해당 세션에서는 음성이 나타나지 않을 수 있습니다(프리셋 동작이며 플러그인 버그가 아닙니다).
- "사이드바 불투명도"는 DSH의 `sidebarCol / detailsCol` 열과 서드파티 better-sidebar의 `data-dsh-panel / data-dsh-pane` 속성에 적용됩니다. better-sidebar 미설치 시 오른쪽 규칙은 아무것도 하지 않으며 메인 UI에 영향이 없습니다.
- 본 플러그인은 설정에 **환경 변수를 읽지 않습니다**. 설정은 `~/.dsh/xiao-theme.json`과 컴파일 시 기본값만 사용합니다.
